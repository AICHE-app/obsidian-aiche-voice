# Contributing

Thanks for helping make AICHE Voice better.

## Report a bug

Open an issue at https://github.com/AICHE-app/obsidian-aiche-voice/issues and include:

- what you did and what you expected
- what happened instead
- your Obsidian version, the plugin version, and your platform (for example macOS, Windows, Android, iOS)

Never paste your sign-in code, tokens, or anything from your account into an issue.

## Ask for a feature

Open an issue describing what you want to do and why. Tell us how you use the plugin today.

## Code

This repository holds the released plugin files. The source code is kept in a separate private repository, so pull requests here can't be merged. Every release is built from that source and verified by the Obsidian community directory.

## Help with your account

For sign-in, subscription or billing questions, go to https://aiche.app/help.
